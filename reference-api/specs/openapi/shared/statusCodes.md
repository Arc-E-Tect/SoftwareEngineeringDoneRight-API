Sometimes your API call will generate an error or return a HTTP status code.
Here you will find additional information about what to expect the request is incorrect, or we fail to properly process your request.

#### The below table defines the HTTP Status codes that this API may return.


  <table>
      <tr>
        <td><b>HTTP Status Code</b></td>
        <td><b>Summary</b></td>
        <td><b>Description</b></td>
      </tr>
      <tr>
        <td>200</td>
        <td>OK</td>
        <td>The request is processed successfully</td>
      </tr>
      <tr>
        <td>201</td>
        <td>Created</td>
        <td>The request was successfully executed</td>
      </tr>
      <tr>
        <td>202</td>
        <td>Accepted</td>
        <td>The request is accepted successfully</td>
      </tr>
      <tr>
        <td>204</td>
        <td>No content</td>
        <td>The response contains no content</td>
      </tr>
  </table>
