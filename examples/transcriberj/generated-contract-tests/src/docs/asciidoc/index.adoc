A catalogue of books: add a book, read one, and list the catalogue a page at a time.

Every example on this page is a request the documentation tests sent to the running service, and the response it gave.
The fields are described by the contract itself.

== Listing the catalogue

`GET /books` answers with one page of the catalogue, in ISBN order.
`page` is the page, the first being `0`; `size` is the number of books on a page, 20 unless asked otherwise, and at most 100.
